tipos de alamcemanieto con js :
    *localStorage: sirve para conservar informacion sencilla por medio de clave:valor.
    *sessionStorage: sirve para almacenar informacion durante una sesion.
    *IndexedDB: sirve para almacenar cantidades mas grandes de informacion,es estructurada con indices.
    *Cache storage API: sirve para conservar solicitudes HTTP y recursos que la misma aplicacion necesita, especialmente cuando trabajamos offline 
nota: este tipo de lamacenamisnto pertenece al entorno de navegador no son funciones esenciales de VUE.
